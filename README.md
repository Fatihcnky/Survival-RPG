# Krallık Yolu

Köy kurma ve hayatta kalma stratejisi. Köyünü kur, halkı görevlendir, mevsimlere ve haydut baskınlarına hazırlan, komşu krallarla diplomasi yap, çağ atla ve krallığını ilan et.

## Oynama
`index.html` dosyasını tarayıcıda aç (ya da APK'yı telefona kur).

## Android APK
Repoya her push'ta GitHub Actions oyunu otomatik APK'ya çevirir:
**Actions** sekmesi → son çalışma → en altta **KrallikYolu-APK** → indir ve telefona kur.

## Dosyalar
- `js/data.js` bina, birim, teknoloji, görev tabloları
- `js/core.js` harita, yol bulma
- `js/units.js` köylü işleri, savaş, bina güncellemesi
- `js/sim.js` ekonomi, çağ/ünvan, kayıt
- `js/ai.js` olaylar, haydut baskınları, krallar, pazar
- `js/render.js`, `js/ui.js`, `js/input.js` çizim ve arayüz
